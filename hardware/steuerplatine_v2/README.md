# Steuerplatine V2 – Fertigungsdaten

Platine 100 × 92 mm, 2 Lagen. Diese Dateien kannst du bei jedem Platinenfertiger hochladen:

| Datei | Inhalt |
|---|---|
| [`steuerplatine_gerber.zip`](steuerplatine_gerber.zip) | Gerber- und Bohrdaten |
| [`steuerplatine_stueckliste_JLC.csv`](steuerplatine_stueckliste_JLC.csv) | Stückliste mit JLCPCB-Bauteilnummern |
| [`steuerplatine_bestueckung_JLC.csv`](steuerplatine_bestueckung_JLC.csv) | Bestückungspositionen (CPL) |

Das **ESP32-H2-DevKitM-1 (N4)** wird nicht bestückt, sondern von dir auf die Platine gesteckt.
Steckbrücken J12/J13: beide immer auf dieselbe Seite (rechts „ORIG“ = Originalgeber, links „VOT“ = Votronic).

Einbau und Anschluss: siehe [Haupt-README](../../README.md#steuerplatine--notwendig).
Dies ist ein Hobbyprojekt – Nutzung und Einbau auf eigene Gefahr, keine Gewährleistung.
