Wohnmobil-Display – Installer

Firmware direkt aus dem Browser auf dein Display spielen – ohne zusätzliche Software.

Benötigt Chrome oder Edge am Computer (Windows, Mac oder Linux) und ein USB-Datenkabel (kein reines Ladekabel). Safari, iPhone/iPad und Android werden nicht unterstützt.

1. Display anschließen und installieren

Display per USB-C an den Computer anschließen, dann auf „Installieren“ klicken.

Waveshare ESP32-S3-Touch-LCD-7B (7 Zoll, 1024×600) Version –
Dein Browser unterstützt das leider nicht – bitte Chrome oder Edge verwenden. Diese Seite muss über HTTPS geöffnet werden.

2. Steuerplatine (ESP32-H2) einmal installieren

Das ESP32-H2-Board der Steuerplatine bekommt seine Firmware einmal vor dem Einbau: Board an der Buchse „USB“ mit dem Computer verbinden und auf „Installieren“ klicken. Spätere Updates der Steuerplatine installiert das Display selbst über WLAN.

Steuerplatine – ESP32-H2-DevKitM-1 Version –
Dein Browser unterstützt das leider nicht – bitte Chrome oder Edge verwenden. Diese Seite muss über HTTPS geöffnet werden.

3. Hinweise zur Verbindung

  • Im Auswahlfenster heißt das Display z. B. „USB JTAG/serial debug unit“ oder „USB Single Serial“ – einfach auswählen.
  • Werden mehrere Einträge angezeigt: Display kurz abziehen, Fenster neu öffnen, wieder anstecken – der neue Eintrag ist der richtige.
  • Kein anderes Programm darf gleichzeitig auf den USB-Anschluss zugreifen (z. B. Arduino IDE, serieller Monitor).
  • Während der Installation das Kabel nicht abziehen. Danach startet das Display von selbst neu.

4. Nach dem ersten Start: testen und freischalten

  1. Das Display zeigt Chip-ID und Freigabecode, z. B. AA:BB:CC:DD:EE:FF 1234.
  2. Mit „Test starten“ kannst du das Display 72 Betriebsstunden kostenlos ausprobieren.
  3. Zum dauerhaften Freischalten: bezahlen und dabei die Zeile vom Display eintragen – Ablauf siehe Anleitung.
